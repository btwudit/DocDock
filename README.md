# DocDock

DocDock is a small project I’m building to make handling documents easier.

This repository contains two parts:

- **Website:** An HTML-based website for DocDock.
- **Browser Extension:** A folder containing the files required to run DocDock as a browser extension.

I'm building this project to explore a simpler way of managing and working with documents. It's still a work in progress, and I'll keep improving it as I build more features.

Made with curiosity and a lot of learning!
